# Developer Tips

Commands the assignment doesn't require but make day-to-day work
smoother. Run all commands from the repo root unless noted.

---

## Alembic (database migrations)

The `app` container automatically runs `alembic upgrade head` via the
one-shot `migrate` compose service on startup. The commands below are
only needed for local iteration or generating new revisions.

| Goal | Command |
|---|---|
| Apply all pending migrations against the running db container | `docker compose run --rm migrate` |
| Apply against a host-side Postgres (uvicorn workflow) | `alembic upgrade head` |
| Generate a new revision from current ORM models | `alembic revision --autogenerate -m "describe_the_change"` |
| Show current revision in the database | `alembic current` |
| Show full migration history | `alembic history --verbose` |
| Downgrade one step | `alembic downgrade -1` |
| Downgrade everything (drop all tables) | `alembic downgrade base` |
| Print the SQL without applying (dry-run) | `alembic upgrade head --sql` |

**Always review autogenerated migrations before committing** — Alembic
catches column adds/drops cleanly but can miss CHECK-constraint changes,
column reorderings, and index renames.

## Cache cleanup

Sometimes a stale cache hides a real bug (especially after dependency
bumps or migration changes). Nuke options, from least to most aggressive:

```bash
# Python bytecode + tool caches (safe; rebuilds on next run)
find . -type d -name "__pycache__" -exec rm -rf {} +
rm -rf .pytest_cache .ruff_cache .ty_cache .coverage htmlcov

# Frontend build + Vite cache
rm -rf frontend/.vite frontend/dist frontend/node_modules/.cache

# Frontend node_modules (forces a fresh npm install)
rm -rf frontend/node_modules
cd frontend && npm install

# Docker — drop containers but keep the db volume
docker compose down

# Docker — drop containers AND wipe the db volume (full reset)
docker compose down -v
docker compose up --build
```

PowerShell equivalents for the `find` / `rm -rf` commands:

```powershell
Get-ChildItem -Path . -Recurse -Directory -Filter "__pycache__" | Remove-Item -Recurse -Force
Remove-Item -Recurse -Force .pytest_cache, .ruff_cache, .ty_cache, .coverage, htmlcov -ErrorAction SilentlyContinue
```

## When to reach for which

- **Tests fail after a migration:** `docker compose down -v && docker compose up --build` — wipes the db volume so the new migration runs against a clean schema.
- **Ruff complains about a file that looks right:** `rm -rf .ruff_cache && ruff check .` — clears stale lint state.
- **Frontend behaves weirdly after a dep bump:** `rm -rf frontend/node_modules frontend/.vite && cd frontend && npm install` — fresh install.
- **pytest skips a test you know exists:** `rm -rf .pytest_cache` — clears the collection cache.
